Backs md §4. For VERTICAL kinds (MIM/poly-poly) transforms never swap plates (stack order is process-fixed), only strap/pin geometry.

Backs md §5. Shield contains fringing (allows narrow dummies), blocks coupling; well/NBL isolates the bottom plates from substrate noise.
