# Optimal analog layout: implementation and research roadmap

## Objective and stopping rule

"Optimal" is a constrained multi-objective problem, not one scalar:

1. LVS match.
2. Zero blocking DRC and zero hard contract violations.
3. Fully routed with no resource overuse and all parasitic budgets met.
4. Pareto improvement of die area, routed wirelength, via count, resistance,
   and capacitance.

Area and PEX are correlated, but they are not identical. A smaller die can
increase detours, coupling, low-metal resistance, or via count. The feedback
engine therefore compares feasibility lexicographically and, only within the
same feasibility class, compares a first-iteration-normalized physical
objective. It records every absolute best but resets the plateau counter only
for a material (default 0.5%) improvement. A first clean layout no longer ends
the search; repeated lack of material improvement does.

## Constraint consumption

| Constraint | Cell generation | Placement | Routing/signoff | Remaining gap |
|---|---|---|---|---|
| Matching tier | MOS dummies, LOD/WPE geometry | symmetry, CC, proximity | matched R/C feedback | derive budgets from operating point |
| Unitization | MOS fields exist | grouped variants | route comparison | orchestrator must fully map extracted unit counts after grouping |
| Isolation/guard ring | ring generator exists | hard pair gaps | DRC feedback | connect generated rings and close their resistance contract |
| LDE/environment | MOS WPE/LOD geometry | stress and distance terms | DRC | four-edge WPE and metal-over-gate geometry checks |
| Net class | n/a | net weighting | order/weight | current-aware widths and shielding topology |
| Parasitic/differential | variant feedback | pin-aware HPWL | R/C and matching contracts | coupling-aware extraction during search |
| Crosstalk/straight | n/a | feedback gap/alignment | clearance/straight checks | concurrent differential/symmetric routing |
| Antenna/ESD/current flow | metadata only | mostly unconsumed | contracts incomplete | diode insertion, current density, EM/IR and ESD topology |

Unconsumed hard constraints must not be treated as satisfied. The contract
ledger should remain the audit mechanism, while each stage consumes only
measurements it can actually enforce.

## Cell library and selection

The implemented selection loop now remembers the variant actually placed. If
that variant reproduces a pin-access, congestion, R/C, or matching failure, its
loss increases and the next iteration explores another candidate. Detailed
placement receives the same learned loss and the real pin offsets of every
variant, avoiding the former conflict where the cell closure selected one
variant and placement silently restarted at variant zero.

Electrically equivalent aspect spaces are expanded for resistor folds,
capacitor unit grids, BJT device arrays, and diode arrays. Further high-value
library work, in order:

1. MOS model flavors and marker layers: LV/HV/native/DMOS/LDMOS.
2. PDK-correct MiM, MoM, varactor, poly/diffusion/high-R resistor families.
3. Merged primitives: differential pairs, mirrors, resistor/capacitor arrays,
   shared diffusion, shared dummies, local source/drain rails.
4. Guard-ring/tap/well variants with routed ring ports and resistance checks.
5. EM-characterized inductor transformers and baluns. Do not vary turns or
   trace width without an EM/electrical model because that changes the device.
6. ESD clamps, pad cells, level shifters, substrate contacts, and power straps.

ALIGN's composition-first approach supports this direction: recognize
hierarchy, generate correct-by-construction primitives, then assemble them
under geometric and electrical constraints.

## Placement

The placer now uses variant- and orientation-specific physical pin HPWL.
Orientation and direct-abutment moves are discrete SA operations, so the
optimizer can reach states that continuous random displacement would almost
never hit.

Bounding-box non-overlap is intentionally not a universal constraint. For two
connected cells, candidate transforms are generated by touching compatible
same-net pin rectangles. The combined geometry is checked with the actual DRC
deck. Only a clean transform can waive footprint overlap, and compaction treats
an active direct connection as a rigid cluster. Arbitrary overlap, or overlap
across an explicit isolation constraint, remains penalized. This enables true
zero-length connections without making DRC an afterthought.

Next placement steps:

1. Cache DRC/LVS-qualified abutments by `(cell, variant, orientation)` and add
   90-degree transforms for RF/passive cells.
2. Qualify merged transforms with local LVS as well as DRC, then merge touching
   same-net polygons before extraction.
3. Replace center-bin density with exact polygon/bin occupancy and local
   Lagrange multipliers.
4. Finish the ASF-B*-tree seed with contour packing and symmetry-feasible
   subtree operations; the current tree implementation is not yet a robust
   contour packer.
5. Add P/N/well bands, thermal maps, and current-flow orientation costs.

RePlAce demonstrates why local density multipliers and layer-aware,
router-measured cell inflation outperform a global density penalty.

## Routing and feedback

PathFinder history is now carried between backend iterations with decay. The
router exports actual history hotspots, successful landing displacement, and
failed pin claims. Placement inflation is derived from those measurements,
not from routed-wire midpoints. Pin-access failure targets a cell variant; only
true no-path/capacity failure requests global spreading.

Next routing steps:

1. Per-layer pitch, width, spacing, and via-rule grids from the deck.
2. Multiple legal access points per pin, via-in-pin enclosure, and access
   pattern scoring before routing.
3. Steiner/trunk-and-tap topology for multi-finger straps and large nets.
4. Concurrent differential/symmetric routing with length, layer, via, R, C,
   and coupling matching in the search state rather than post-hoc mirroring.
5. General DRC marker repair: map spacing/EOL/notch/via markers to resources,
   rip up only affected nets, block the failing pattern, and negotiate again.
6. Bias-current-driven wire/via sizing, EM/IR, antenna repair, and shielding.
