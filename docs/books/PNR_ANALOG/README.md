# Analog P&R Automation Engine -- Analog-Enriched Specification Set

This directory contains the analog-enriched versions of the PNR specification documents. Each document in `PNR_ANALOG/` is a companion to the corresponding document in `PNR/`, extended with domain knowledge from three textbooks:

- **[Hastings]** -- Alan Hastings, *The Art of Analog Layout*, 3rd Ed. (AOAL)
- **[Lienig]** -- Jens Lienig & Claus Scheible, *Fundamentals of Layout Design for Electronic Circuits* (FOLD)
- **[Graeb]** -- Helmut Graeb (ed.), *Analog Layout Synthesis* (ALS)

## Architecture Rule

Analog considerations are **companion sections** within each enriched spec. Every enriched document preserves the full original spec content and appends `.A Analog Considerations` and `.B Analog-Algorithm Interface` subsections to each numbered section. The core algorithms remain drop-in replaceable: a team can implement the base algorithm from the original section and later activate analog extensions by reading the companion sections. No original algorithm is deleted or restructured.

## Research Foundation

This enriched specification set synthesizes all sources from the original PNR/ set plus:

- **Hastings, *The Art of Analog Layout*, 3rd Ed.** -- Chapters 2-8, 10, 12-15. Provides the 25 resistor matching rules, 24 MOS transistor matching rules, 13 capacitor matching rules, three matching tiers, five CC rules, guard ring theory (4 types), ESD protection, die assembly methodology, and the 17-point final layout checklist.
- **Lienig & Scheible, *Fundamentals of Layout Design for Electronic Circuits*** -- Chapters 4-7. Provides the design flow model (full-custom for analog, meet-in-the-middle), three-tier matching classification, five CC rules, substrate noise and latchup theory, ESD ground ring rules, and design rule robustness concepts.
- **Graeb (ed.), *Analog Layout Synthesis*** -- Chapters 1-7. Provides topological placement representations (sequence-pairs, B*-tree, ASF-B*-tree, HB*-tree), deterministic Plantage enumeration, symmetric routing theory (ROAD, ANAGRAM, ILAC), sensitivity-based routing, constraint engineering methodology, and layout-aware sizing feedback.

## How to Use This Document Set

**If you are the architect:** Read `00_ANALOG_PRINCIPLES.md` (the shared reference), then `00_MASTER_ARCHITECTURE.md` (enriched), then `11_CROSS_STAGE_REVIEW.md` (the review), then `08_OPTIMAL_LAYOUT_CHECKLIST.md` (enriched checklist with pointers).

**If you are implementing S0:** Read `01_S0_CELL_GENERATION.md` (enriched), focusing on the `.A Analog Considerations` subsections. Cross-reference `00_ANALOG_PRINCIPLES.md` Sections 1-2 for matching and LDE models.

**If you are implementing S1:** Read `02_S1_CONSTRAINT_EXTRACTION.md` (enriched). Cross-reference `00_ANALOG_PRINCIPLES.md` Section 5 for the Hierarchy of Needs that drives constraint priority.

**If you are implementing S2:** Read `04_S2_PLACEMENT_DETAILED.md` (enriched). Cross-reference `00_ANALOG_PRINCIPLES.md` Sections 2-4 for the LDE and thermal models used in GP terms.

**If you are implementing S3:** Read `05_S3_ROUTING_DETAILED.md` (enriched). Cross-reference `00_ANALOG_PRINCIPLES.md` Sections 3-4 for parasitic budgets and reliability models.

**If you are implementing S4:** Read the S4 sections in `03_S2_S3_S4_INTERFACES.md` (enriched). Cross-reference `00_ANALOG_PRINCIPLES.md` Section 4 for sign-off models.

**If you are porting to a new PDK:** Read `10_BENCHMARK_VALIDATION_PDK.md` (enriched), especially Section 3.2.A (analog extensions to layers.json) and Section 3.3.A (analog porting checklist).

**If you are training ML models:** Read `07_ML_TRAINING_SPEC.md` (enriched), focusing on the analog training data requirements.

**If you are reviewing the specs for completeness:** Read `11_CROSS_STAGE_REVIEW.md` and `08_OPTIMAL_LAYOUT_CHECKLIST.md` (enriched with pointers).
