# 6.6 Layout Matching Concepts

> **Chapter context**: Special Layout Techniques for Analog IC Design

## Key Concepts

Device matching is the practice of ensuring that two or more devices intended to have a precise electrical ratio (or equality) actually achieve that ratio on silicon. Mismatches arise from five broad categories of physical effects, each addressed by a distinct set of layout concepts.

---

### 6.6.1 Internal Device Fringe Effects

Internal device fringe effects are deviations from ideal device behavior caused by edge phenomena *within* the device itself. These are additive -- they do not scale with device size -- so they distort the intended ratio whenever matched devices differ in geometry.

#### Resistors

Two fringe effects dominate:

1. **Width variations from edge shifts.** Tolerances in exposing and etching shift the edges of the resistor body by a fixed amount (e.g., ~50 nm). For poly resistors and PSD/NSD resistors (whose width is set by the STI opening), this shift is additive.
   - Example: Two resistors with nominal widths 1 um and 0.5 um and a 50 nm additive width increase. The intended ratio 1/0.5 = 2 becomes (1.05)/(0.55) = 1.91, a **4.5% mismatch**.
   - For Nwell resistors, lateral outdiffusion widens the device but is *not* handled by layout pre-sizing, so it only appears in resistors with different widths.
   - **Conclusion: Matched resistors must always have the same width.**

2. **Inhomogeneous current flow in resistor heads.** The resistor "head" (the region near the contact) has a different sheet resistance R_H from the body R_sq. When two resistors differ in length, the ratio of heads to body differs and creates mismatch.
   - For a required ratio r = R1/R2 > 1 with equal widths (w1 = w2 = w), the lengths are related by:
$$l_1 = r \cdot l_2 + l_{corr}, \quad l_{corr} = 2(r-1) \cdot \frac{R_H}{R_{sq}} \cdot w \tag{6.10}$$
   - The correction length l_corr compensates for the "missing" head resistances. However, R_H and R_sq values from the PDK are nominal; their real values have process tolerances, so a residual error always remains.
   - **Solution: Split resistors into identical "basic resistors" of the same width AND length**, then connect them (preferably in series) to achieve the desired ratio. For ratio r = 3, use three identical unit resistors in series for R1 and one unit for R2.

> **Rule of thumb.** Matched resistors must always have the same width and the same length. Use splitting to create ratios r != 1. Increasing w and l together (keeping number of squares constant) further reduces the relative impact of fringe effects and improves matching precision.

#### MOS-FETs

The field-oxide opening (channel width w) and poly gate finger width (channel length l) both suffer stochastic edge shifts. Additional deterministic effects include:
- Sub-diffusion of source/drain zones under the poly gate shortens the channel length by a constant amount.
- In processes with LOCOS field oxide, the bird's beak effect significantly reduces the effective electrical channel width.

Since these are additive (non-scaling) effects, **matching MOS-FETs must have uniform channel length and width**. The w/l ratio is set by *folding* -- splitting a wide transistor into multiple identical fingers.

- Example: A 1:2 current mirror where M1 has w=10, l=2 and M2 has w=20, l=2. Without folding, the two transistors have different widths and fringe effects distort the ratio (bad matching). Folding M2 into two fingers of w=10 each gives identical gate geometries (good matching).

> **Rule of thumb.** Matching MOS-FETs always have uniform channel length. W/L ratios are set by folding so that all single-transistor fingers have the same length and width.

#### Capacitors

For an ideal parallel-plate capacitor, capacitance is proportional to plate area A = w * l (Eq. 6.11). However, **fringe fields** at the plate edges contribute additional capacitance proportional to the perimeter P = 2w + 2l (Eq. 6.12), not the area. For matched capacitors C1 and C2, both the area ratio and the perimeter ratio must equal the desired capacitance ratio:

$$P_1 / P_2 = A_1 / A_2 = C_1 / C_2 \tag{6.13}$$

**Approach 1 -- Splitting into identical unit capacitors.** Build both capacitors from identical square sub-capacitors connected in parallel. Because all units are identical, fringe fields and main fields are in the same proportion automatically, and fabrication tolerances affect all units equally. This is the higher-precision method.

**Approach 2 -- Individual stretching (area-to-perimeter matching).** Make C1 square (w1 = l1) and solve Eq. 6.13 for C2's dimensions:

$$w_2 = \frac{C_2}{C_1}\left(1 + \sqrt{1 - \frac{C_1}{C_2}}\right) \cdot w_1 \tag{6.14}$$

$$l_2 = \frac{C_2}{C_1}\left(1 - \sqrt{1 - \frac{C_1}{C_2}}\right) \cdot w_1 \tag{6.15}$$

- C1 must be the smaller capacitor for real solutions to exist.
- Advantage: saves area since no splitting is needed.
- Disadvantages: the aspect ratio of C2 degrades rapidly as C2/C1 grows (already l2/w2 = 3.73 at C2:C1 = 1.5). Fabrication tolerances cause residual mismatch that scales disproportionately with increasing ratio. **Not suitable for high-precision matching.**

#### NPN Transistors

Total current is determined by emitter area. In older (non-STI) processes, lateral emitter outdiffusion caused a large fringe effect -- only duplicating identical emitters could match devices. In modern STI processes, STI cuts the outdiffusion but stochastic edge shifts in the STI opening still cause fringe effects. Matching requires **uniform emitter structures**. Stretching emitters is possible only parallel to the base contact (to avoid current crowding), but yields lower precision than duplication.

#### PNP Transistors (Lateral)

These can only be sized by replicating their fixed basic structure, so matching is inherently done by duplication. Two layout styles exist:
- **Multi-emitter**: separate emitter structures in a common n-well (common base), each with its own collector ring.
- **Multi-collector**: a shared emitter and base with collector rings cut radially (used in older processes with feature sizes > 1 um).

### 6.6.2 Matching Concepts for Unknown Gradients

Fabrication tolerances create location-dependent parameter variations (e.g., Nwell sheet resistance, gate oxide thickness) across the wafer and within each die. These gradients are **stochastic and unknown** -- we cannot predict their direction or magnitude.

#### Minimum Distance Rule

The larger the physical distance between matched devices, the more an unknown gradient can contribute to mismatch. Even with perfect fringe-effect handling, devices placed millimeters apart will see different local process parameters.

> **Rule of thumb.** Matched devices should always be placed as close as possible to each other in the layout.

#### Interdigitation

Splitting devices and interleaving their sub-units reduces the *effective distance* between matched devices. For example, splitting device A (ratio 2) into A1, A2 and interdigitating with device B as [A1, B, A2] brings the centroid of A closer to B.

#### Common Centroid Layout

The ideal case is a **common centroid** arrangement where the centroids of all matched devices coincide exactly, achieving an effective "zero distance."

**Mathematical proof for linear gradients:** Assume the parameter of interest varies linearly as y = mx + b across the layout. For devices A (split into A1, A2) and B:

- Layout variant (I) -- grouped: A1, A2, B at positions x1, x2, x3. Then A/B = [m(x1+x2) + 2b] / [mx3 + b]. Since x1+x2 < 2*x3, the ratio deviates from 2.
- Layout variant (II) -- common centroid: A1, B, A2 at positions x1, x2, x3 where x1+x3 = 2*x2. Then A/B = [m(x1+x3) + 2b] / [mx2 + b] = [2mx2 + 2b] / [mx2 + b] = **exactly 2**.

Common centroid layouts always feature **axis or point symmetry**. A 1:2:4 current mirror, for example, requires folding all transistors to unit fingers and arranging them in a symmetric 2D pattern (e.g., D-C-C-B-B-C-C-D / D-C-C-B-A-C-C-D mirrored about the symmetry axis, with D = dummy elements).

> **Rule of thumb.** Splitting and interdigitating subdevices reduces effective distance. A common centroid configuration (zero effective distance) is optimal and always features axis or point symmetry.

### 6.6.3 Matching Concepts for External Device Fringe Effects

Even with identical, closely packed devices, elements at the **boundary** of a matching group have different surroundings from those in the center. Neighboring structures outside the group can cause local inhomogeneities during fabrication (e.g., etchant saturation differences).

#### Dummy Elements

The solution is to surround the matching group with **dummy elements** -- structures identical to the real devices but with no electrical function. This ensures uniform "neighborhood conditions" for all active devices. Examples:
- Dummy poly gate fingers ("D") at both ends of interdigitated transistor arrays.
- Dummy resistors at both ends of matched resistor series.
- 2D capacitor arrays completely surrounded by dummy capacitors (consumes significant area).

#### Well Proximity Effect (WPE)

Higher dopant concentrations occur within approximately **1 um of the well boundary** due to ion scattering during implantation. This can severely alter V_th of MOS-FETs and cause large mismatch.

> **Countermeasure:** Place matching MOS-FETs at a distance > 1 um from the well border.

#### Trench-Isolation Stress

Shallow and deep trench isolations (STI, DTI) exert mechanical pressure on adjacent silicon. Due to different coefficients of thermal expansion (CTE) between silicon and oxide, the pressure is temperature-dependent. This pressure:
- **Increases** hole mobility
- **Decreases** electron mobility

This can cause large mismatches. Dummy elements should be used as a standard countermeasure.

### 6.6.4 Matching Concepts for Known Gradients

Some gradients are predictable from the chip's use case -- primarily thermal gradients and mechanical stress from packaging.

#### Thermal Gradients

Integrated circuits have extremely high power densities. Heat is generated locally by individual devices (especially power transistors / DMOS-FETs), creating non-uniform temperature distributions. Key facts:
- DMOS-FETs can produce temperature differences of **several tens of Kelvin** across a chip.
- Power transistors are placed at chip boundaries due to high currents, so their heat distributions can be estimated.
- The temperature *difference* (not absolute temperature) is what matters for matching.

> **Rule of thumb.** Place matched devices along **isotherms** (lines of constant temperature) to minimize temperature-related mismatch. This applies to common centroid layouts as well.

#### Mechanical Stress from Packaging

When a chip is packaged, the injected mold mass deforms the die (like a sail in wind). The resulting mechanical stress affects carrier mobility and thus electrical properties. The stress pattern is characterized by **isobars** (lines of constant mechanical pressure):
- **Lowest stress**: chip center (best for matching).
- **Highest stress / steepest gradients**: chip corners (worst for matching).
- **Moderate gradients**: middle of chip edges.

> **Rule of thumb.** Avoid chip regions with high stress gradients (especially corners) for tight matching. The chip center is ideal. The two chip centerlines also yield good results.

### 6.6.5 Matching Concepts for Orientation-Dependent Effects

#### Alignment Tolerances

Mask alignment tolerances are unavoidable. If all matching elements are oriented the same way, any misalignment affects them uniformly -- no mismatch results. Example: if contact holes shift upward relative to poly, vertical resistors are unaffected while horizontal resistors see off-center contacts (changed head resistance). Parallel-oriented resistors always match regardless of the shift direction.

#### Carrier Mobility and Crystal Orientation

Mechanical forces affect carrier mobility differently depending on crystal lattice alignment. All elements in a matching group must be oriented identically so they experience the same mobility shift.

> **Rule of thumb.** Orientation is irrelevant for capacitors. For all other devices (resistors, transistors), matched elements should always be aligned parallel to one another.

#### Thermoelectric (Seebeck) Effect

Every interface between two different materials (p-n junction, silicon-metal, metal-metal) produces a potential difference. These voltages normally cancel in a circuit, but because they are temperature-dependent (governed by the material-specific **Seebeck coefficient**), they do NOT cancel when contact boundaries are at different temperatures. The resulting **Seebeck voltages** range from **0.1 to 1 mV/K** at interfaces.

**Mitigation strategies:**
1. **Antiparallel current flow** (preferred): In split devices, route current in both directions (half in each direction) so Seebeck voltages cancel within each device. This is used in common centroid layouts.
2. **Same-direction current flow** (fallback): If antiparallel flow is not feasible, ensure that currents in all matched devices flow in the same direction so the Seebeck voltages are equal.

> **Warning:** Do not blindly follow geometrical symmetry axes -- mirroring about a geometric axis can reverse current direction in matched devices, which is harmful. "Matching symmetry" (same current direction) takes precedence over "geometrical symmetry."

### 6.6.6 Summary of Matching Concepts

The textbook provides a tiered classification of matching measures by stringency:

#### (a) Normal Matching Requirements (mandatory for any matching)
| Measure | Devices | Effect Addressed |
|---------|---------|-----------------|
| Same device type | All | Prerequisite |
| Same size and shape (splitting into identical basic elements) | All | Internal device fringe effects |
| Minimum distance | All | Unknown gradients |
| Same orientation | R, T | Alignment tolerances, carrier mobility |

#### (b) Higher Matching Requirements
| Measure | Devices | Effect Addressed |
|---------|---------|-----------------|
| Same area-to-perimeter ratio (alternative to splitting) | C | Internal device fringe effects |
| 1D or 2D interdigitation | All | Unknown gradients |
| Placement along isotherms (same temperature) | All | Thermal gradients (known) |
| Same environment via dummy elements | All | External device fringe effects |
| Consider current flow direction | R, T | Thermoelectric (Seebeck) effect |
| Increase device dimensions | R, T | Internal device fringe effects |

#### (c) Highest Matching Requirements
| Measure | Devices | Effect Addressed |
|---------|---------|-----------------|
| Common centroid layout | All | Unknown gradients |
| Placement in low-stress chip regions | All | Carrier mobility |
| Symmetrical routing | All | Circuit-function-dependent |
| Distance to well border > 1 um | M | Well proximity effect |
