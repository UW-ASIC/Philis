# 3.1 Introduction to Deterministic Analog Placement

> **Chapter 3**: Deterministic Analog Placement by Enhanced Shape Functions (Strasser, Eick, Graeb, Schlichtmann)
> **Part**: Part I: Placement

Modern integrated circuits contain both digital and analog parts. While digital circuits can be designed using a variety of automated layout approaches, **analog circuits are still manual and error-prone** in many cases. The placement and routing of an analog circuit have a severe impact on circuit function and performance. Layout constraints are defined to make sure the circuit fulfills performance specifications. This chapter presents a **comprehensive and deterministic methodology** for analog layout design automation: an approach to automatically generate constraints for analog circuits, and a placement algorithm called **Plantage** that calculates a Pareto front of placements with respect to different aspect ratios.

## Key Concepts

### 3.1.1 Definitions

The chapter establishes formal definitions used throughout:

- **Device** (Def. 3.1): An elementary part of the circuit (e.g., a transistor). The set of all devices is referred to as $D$.
- **Module** (Def. 3.2): The smallest item the placer deals with. Represented by a rectangle on the placement plane. Modules are referred to by Latin lowercase letters.
  - A device consists of one to several modules. Several physical transistors (represented by different modules) may be interconnected to form one logical transistor (represented by a single device).
  - $\mathcal{M}$ is the set of modules. For every module $m \in \mathcal{M}$, the lower left corner coordinates are described by $x_m$ and $y_m$, and the width and height are $w_m$ and $h_m$.
- **Center of Gravity (COG) of a module** (Def. 3.3): Defined as:
  $$x_{\text{COG}}(m) = x_m + \frac{w_m}{2}$$
  $$y_{\text{COG}}(m) = y_m + \frac{h_m}{2}$$
  In vector form: $\mathbf{x}_{\text{COG}}(m) = \binom{x_{\text{COG}}(m)}{y_{\text{COG}}(m)}$
- **Distance between modules** (Def. 3.4): The distance $d(m, n)$ is denoted by $d(m, n)$, defined as the minimum of the vertical and horizontal distance:
  $$d(m, n) = \min(d_h(m, n),\; d_v(m, n))$$
  where:
  $$d_h(m, n) = \max\left(|x_{\text{COG}}(m) - x_{\text{COG}}(n)| - \frac{w_m + w_n}{2},\; 0\right)$$
  $$d_v(m, n) = \max\left(|y_{\text{COG}}(m) - y_{\text{COG}}(n)| - \frac{h_m + h_n}{2},\; 0\right)$$
- **Group** (Def. 3.5): A group $G$ is defined as a set of modules or a set of groups, which are intended to be placed in close proximity.
  - A group $G^b$ consisting only of modules ($G^b \subseteq \mathcal{M}$) is called a **basic group**.
  - The set of all basic groups is called $\mathcal{G}^b$, which is the power set of $\mathcal{M}$ without the empty set: $G^b \in \mathcal{G}^b = \mathbb{P}(\mathcal{M}) \setminus \{\emptyset\}$
  - A group $G^i$ of hierarchy level $i \geq 1$ only contains other groups $G^{i-1}$. It is called a **hierarchical group of hierarchy level** $i$. The set of all possible groups for level $i$ is the power set of $\mathcal{G}^{i-1}$ without the empty set: $G^i \in \mathcal{G}^i = \mathbb{P}(\mathcal{G}^{i-1}) \setminus \{\emptyset\}$
- **modulesOf(G)** function: Returns the set of all modules of group $G$. Defined recursively:
  $$\text{modulesOf}(G) = \begin{cases} G, & \text{if } G \in \mathcal{G}^b \\ \bigcup_C \text{modulesOf}(C) & \text{else} \end{cases}$$
  Each module is allowed to be part of only one group.
- **Center of Gravity of groups** (Def. 3.6): Similar to Def. 3.3, the COG of a group is:
  $$\mathbf{x}_{\text{COG}}(G) = \frac{\sum_{m \in \text{modulesOf}(G)} v_m \cdot \mathbf{x}_{\text{COG}}(m)}{\sum_{m \in \text{modulesOf}(G)} v_m}$$
- **Module variants** (Def. 3.7): For any module $m \in \mathcal{M}$, there may be several different alternative layouts. The bounding rectangle of an alternative layout of a module is called a *module variant*. The set of all module variants for $m$ is referred to as $V_m$; a single module variant is denoted by $v_m$. Examples: different numbers of gate fingers of transistors.

### 3.1.2 Analog Circuit Placement Requirements

The placement is generated before routing the circuit and is subject to various constraints formulated to improve **matching** of devices intended to be identical by design. Matching reduces the influence of variations of the process and operating conditions, as well as parasitics. Five key constraint types are identified:

#### Variant Constraints
Restrict the combination of possible realizations (variants) of circuit modules to ensure matching of devices. When a module has a set of possible variants, the placement algorithm faces a higher degree of freedom and better placements can be achieved. However, the combination of different variants is not completely free. For example, a variant constraint ensures that **both transistors of a differential pair are realized with the same number of gate fingers**.

#### Device-Proximity Constraints
Used to make sure that a group of modules is **placed in close proximity**. Due to local variations during fabrication, device parameters show unwanted deviations from each other (also called "mismatch"), which can result in performance degradation. Variations in operating conditions (supply voltage, temperature) may have the same effect. Placing matched devices in close proximity can limit the impact of these variations.

#### Symmetry Constraints
Used for **geometric and electrical reasons**:
- Allow for symmetric routing and reduce the sensitivity to on-die thermal gradients
- Parasitic resistors and capacitors can be balanced on both halves of a differential circuit

For a module $i'$ that is to be placed symmetrically to module $i$ (self-symmetrical modules: $i$ is equal to $i'$), the vertical symmetry constraint is formulated as:

$$\mathbf{v}_i\left(x_i + \frac{w_i}{2} + x_{i'} + \frac{w_{i'}}{2}\right) = \text{const} = x_{\text{sym}}$$

$$\mathbf{v}_i\left(y_i + \frac{h_i}{2}\right) = y_{i'} + \frac{h_{i'}}{2}$$

#### Common Centroid Constraints
Formulated to arrange the centers of gravity for groups of modules. A widely used constraint that improves the beneficial effects of the symmetry constraint. For two groups of modules $A$ and $B$, a common centroid constraint is:
$$\mathbf{x}_{\text{COG}}(A) = \mathbf{x}_{\text{COG}}(B)$$

A differential pair formed by 16 transistors arranged as a1-a8 and b1-b8, where all transistors have the same size and the two groups of transistors share the same center of gravity.

#### Minimum Distance Constraints
Necessary for technological reasons. Three different types exist:

1. **Linear minimum distance constraints**: To manufacture a CMOS circuit, p-channel transistors usually need to be located in wells. Sets of modules can be surrounded by a **guard ring** to prohibit latch-up effects. For both wells and guard rings, areas need to be reserved in the direct surrounding. For a guard ring with width $d_g$:
   $$\forall_{m \in A,\, n \notin A}:\; d(m, n) \geq d_{\min}(m, n),\quad d_{\min}(m, n) \geq 0$$
   The maximum distance required from module $m$ to any other module is $d_{\min}(m)$: $\forall\, d_{\min}(m) \geq d_{\min}(m, n)$

2. **Piecewise-linear minimum distance constraints**: Formulated for special devices requiring more complex minimum distance constraints. A good example is transistors with **deep trench isolation (DTI)**, used for switching high voltages on a chip. Each DTI transistor is directly surrounded by a DTI. The manufacturing process of DTIs is complex, with different layout restrictions. Three ranges of distance between DTI transistors exist:
   - **Range 1**: Directly abutting, sharing a DTI ($d \leq x_{\text{range}}$)
   - **Range 2**: Stretched to the limit, at minimum distance. This is a **forbidden zone** ($\sqrt{} \leq d \leq ?$)
   - **Range 3**: From the positive end of the forbidden zone to infinity
   Formulated by single inequalities with at least two inequalities for disjoint ranges:
   $$d \leq x_{\text{range}} \quad \lor \quad d \geq d_{\text{DTI}}$$

The placement constraints are also crucial for the **routability** of the design. Devices often need to be connected by symmetric wires to balance parasitic resistances and capacitances. A prerequisite for symmetric routing is a **symmetric placement**. Compact layouts are needed for economic reasons, and successful analog layout automation algorithms must produce compact results considering various constraints.

### 3.1.3 Context of This Work

A number of methods for automatic placement constraint generation have been published:

- Methods in [5-7] evaluate **sensitivity analyses** to identify parasitics, matching, and symmetry constraints of a circuit
- The method of [8] classifies nets according to their susceptibility, then identifies **analog building blocks** (e.g., current mirrors) and their matching constraints
- Algorithms in [9-12] use **structural analysis** of the circuit to find symmetry. The underlying subgraph isomorphism problem is solved by graph labeling [9, 12] and recursive detection of symmetric pairs [10, 11]
- Generation of **sizing constraints** is a related problem, using basic building blocks defined by a library from the netlist [13]

For placement representation, two main approaches exist:

1. **Absolute coordinate representations** [14-17]: Constraints are directly formulated using coordinates. These approaches generate placements using **simulated annealing** [18]. Minimum distance constraints are handled as a special cost function term (0 if met, >0 if violated). The search space is $\mathbb{R}^{2N}$ for $N$ modules -- **high dimensionality** leads to long computation times.

2. **Topological representations**: Much smaller search space [19], while still storing all admissible [20] placements without overlaps. Prominent representations include:
   - [[2.1 The O-Tree Algorithm|O-Tree]] [20]
   - [[2.3 The B*-Tree Algorithm|B*-tree]] [21, 22]
   - HBSF/B*F-Tree [23] (see [[2.5 The HB-Tree Algorithm|Chap. 2]])
   - Sequence pair [24]
   - Bounded sliceline grid [25]
   - Corner block list [26, 27]
   - TCG-S [28]
   - **Plantage** (the placer presented in this chapter), based on B*-trees

**B*-tree mechanics**: Each node in a B*-tree represents a module. The rules for placement from a B*-tree without constraints:
- Any node may have up to two child nodes: one left and one right
- The module of a left child is placed above the module of the parent node
- The module of the right child is placed right of the module of the parent node
- In case the $y$-projections of two modules overlap, the module which comes first in a preorder traversal of the B*-tree is placed left of the other module
- The preorder traversal of the tree gives the placement order (e.g., tree ABCD yields preorder ABCD; A and B are placed to the left of C, B is placed to the left of D)

Previous works using simulated annealing [22, 29-32] propose restricting the solution space using symmetry constraints with O-trees [29], B*-trees [22], sequence pairs [30, 31], and sequence pairs with Johnson's priority queue [32]. In [23], a different approach based on two modifications of the B*-tree is presented: handling **symmetry islands** and combining them with the rest of the modules. The authors of [33] presented a placement algorithm with symmetry and other placement constraints, introducing the concept of **dummy nodes in constraint graphs**. All previous works mentioned here use simulated annealing. **In contrast, Plantage is deterministic**.

### 3.1.4 Contributions

Analog integrated circuits are **hierarchically built**. For example, an operational amplifier can be decomposed into a differential input stage and an output stage. The input stage can be divided into a differential pair and several current mirrors. This hierarchy can be described as a **hierarchy tree**, whose leaf nodes are the devices of the circuit. The root node represents the whole circuit. All inner nodes including the root node are denoted as **groups**.

Key contributions of this chapter:

- **Generation of placement rules** based on automatically detected symmetry conditions and basic building blocks
- **First approach** (known to the authors) introducing a **hierarchy concept for placement** of analog integrated circuits, which provides:
  - A prioritization of placement rules by importance
  - A hierarchical clustering of the circuit
  - Circuit-specific constraint information
- **Automatic placement** considering all beforehand generated constraints
- **Computation of a set of possible placements** with different aspect ratios instead of a single solution
- Based upon a **nonslicing topological placement structure, the B*-tree**
- Full enumeration of basic groups, guided by the hierarchy of the circuit
- **Deterministic algorithm**, suitable for parallelization
- Variant selection is integrated seamlessly in the enumeration

The placement algorithm works as follows:
1. Start with **basic groups**; for the basic groups, the complete solution space is enumerated using B*-trees (accelerated using feasibility checks as described in [[1 Topological Placement Representations|Chap. 1]])
2. An algorithm is proposed in Sect. 3.3 to generate a placement for a given B*-tree **considering all constraints for analog circuits**
3. To store all Pareto-optimal placements for basic groups, **enhanced shape functions** are used (described in Sect. 3.4)
4. After all possible placements for basic groups are calculated, the algorithm steps up to the next level in the hierarchy
5. Results of previously calculated placements for basic groups are combined. For the current hierarchy level, the Pareto-optimal results are stored in an enhanced shape function
6. **Suboptimal combinations are removed in every hierarchy level** to limit computational effort in subsequent steps
7. Repeated until the highest hierarchy level is reached, covering the whole circuit

The final result: the enhanced shape function of the whole circuit represents the **Pareto front of optimal layouts with different aspect ratios**. This enables the designer to choose among different valid designs having different aspect ratios -- in contrast to other state-of-the-art approaches that produce a single layout.

## Algorithms & Methods

### Plantage Algorithm Overview

Plantage is a **deterministic, hierarchical** placement algorithm. Its key methodological steps are:

1. **Constraint Generation** (Sect. 3.2): Automatically determine the hierarchy tree of the analog circuit. Constraints are determined automatically and modeled in a **placement requirement graph**. Building blocks are recognized (e.g., current mirrors), and symmetry conditions in the circuit are identified. Prioritized rules are generated, along with constraints and hierarchy information.

2. **B*-Tree Enumeration** (Sect. 3.3): For each basic group, enumerate all B*-tree topologies. For each topology, generate a placement considering all analog constraints (symmetry, matching, proximity, minimum distance).

3. **Enhanced Shape Functions** (Sect. 3.4): Store Pareto-optimal placements as area-optimal placements (shapes) with different aspect ratios. This is the key data structure that enables combining partial results hierarchically.

4. **Hierarchical Assembly** (Sect. 3.5): Combine basic group results level by level up the hierarchy tree:
   - At each level, combine the enhanced shape functions of child groups
   - Remove suboptimal combinations (Pareto filtering)
   - Store results in a new enhanced shape function for the current level

5. **Final Result**: The enhanced shape function of the root node gives the Pareto front of complete circuit layouts.

### Key Properties

| Property | Value |
|----------|-------|
| Representation | B*-tree (topological, nonslicing) |
| Optimization | Deterministic enumeration (not simulated annealing) |
| Output | Pareto front of layouts (multiple aspect ratios) |
| Constraint handling | Integrated into B*-tree generation |
| Parallelizability | Yes (basic groups can be enumerated independently) |

## Connections to Bigger Picture

This sub-chapter introduces Chapter 3, which presents the most comprehensive deterministic approach to analog placement in the book. While [[2.5 The HB-Tree Algorithm|Chapter 2]] focused on topological representations (O-Tree, B*-tree, HB-tree) as general data structures, Chapter 3 applies the B*-tree representation specifically to the analog placement problem with its unique constraints (symmetry, matching, minimum distance). The key innovation is the shift from stochastic optimization (simulated annealing, used by all prior works) to **deterministic enumeration** made tractable by hierarchy and Pareto filtering. The enhanced shape function concept bridges placement and routing by providing a set of valid layouts with different aspect ratios, allowing the router or designer to select the most suitable geometry. This chapter is foundational to understanding how topological representations from Part I are applied to actual analog circuit constraints.
