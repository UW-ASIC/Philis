# 4.5 Advanced Routing Strategies

> **Chapter 4**: Routing Analog Circuits (Dundar & Unutulmaz)
> **Part**: Part II: Routing

## Key Concepts

### 4.5.4 Integrated Placement and Routing

The conventional approach treats placement and routing as **sequential** stages (and within routing, global and detailed routing are also sequential). This means global routing information cannot feed back into placement -- only a rough wire-length estimator is used during placement, producing placements that are suboptimal from the router's perspective.

In analog circuits, however, this integration is feasible and desirable because:
- The **number of nets is relatively small** compared to digital circuits, making simultaneous optimization computationally tractable
- Analog performance is **highly sensitive to actual wire paths** and their parasitics, so early routing awareness during placement leads to better results

**Key systems and approaches:**

- **KOAN/ANAGRAM II** -- A pioneering system for simultaneous placement and routing. The simulated annealing-based KOAN placer is extended to manipulate both devices and wires. Wires are treated like modules with three distinctions:
  - **Representation**: nets must always remain electrically connected to their devices; initial connection quality is unimportant as it improves over time
  - **Moves**: not heavily constrained; effort is channeled into the cost function instead
  - **Cost function**: includes design rule violations, crosstalk, and total net area per connection -- designed to coerce nets into high-quality physical routes over time

- **RACHANA** -- Uses the circuit schematic's graph as the starting point (leveraging the assumption that a well-drawn schematic captures good element distribution). The placement and routing are **intertwined**: each module is placed, then its connections are completed before the next module is placed. The router is gridless and multilayer.

- **GELSA** -- Integrates routing at every step of placement using **slicing structures** represented as trees/strings with **simulated annealing** optimization. To avoid prohibitive runtimes (routing is NP-complete), only approximate routing is performed at each placement step. Considers **two levels of symmetry** simultaneously: global symmetry w.r.t. virtual axes and local symmetry affecting groups of cells.

- **Sequence-pair approach** -- Uses the sequence pair algorithm to place both blocks and wires. Each wire is divided into a set of rectangles, with **wire-connectivity constraints** imposed on the sequence-pair ordering, plus horizontal/vertical constraint graphs for compaction.

- **Hybrid genetic + simulated reannealing** -- A two-stage technique: (1) global placement using a hybrid genetic approach with half-perimeter wire-length estimation for rough but fast search, (2) detailed placement using simulated reannealing with simultaneous minimum-Steiner-tree-based global routing. The global routing cost evaluates placement quality, driving the optimizer toward routing-optimal placements.

- **Tabu-search with tiles** -- Extends integrated P&R to include **constraint transformation**. The circuit is represented geometrically as tiles that can be moved, swapped, routed, and resized. A tabu-search optimizer uses these operations, producing results superior to conventional sequential constraint-transformation-place-route methodology.

### 4.5.5 Global/Detailed Routing

The **two-phase approach** (global then detailed routing) is the most common decomposition. Several systems implement this with varying degrees of integration with placement.

**ALADIN** -- A comprehensive system with tightly integrated global routing and placement:

- **Global routing** uses a **minimum-Steiner-tree** formulation on a weighted channel intersection graph (see [[4.4 Routing Issues for Analog Circuits|Fig. 4.8]]). The problem reduces to finding an optimal subtree spanning the terminal vertices, solved via **Dijkstra's shortest path algorithm**.
- Net-length estimation options: half-perimeter, center-of-mass, complete graph, minimum spanning tree (all Manhattan-distance-based and thus less accurate), and the preferred minimum-Steiner-tree method that also accounts for net sensitivity and channel congestion.
- **Channel congestion** is represented by the number of nets passing through a channel, used as a weight in the global routing graph alongside channel length.
- **Detailed routing** is compaction-based and constructive:
  1. Preprocessing determines wiring order (heuristic: symmetric and central modules first)
  2. Interconnections within each module are wired densely around the module boundary using a **ring router**
  3. The dense module is compacted toward others per placement relationships
  4. Inter-module connections are routed using a **modified maze router** within a small scope
- This compaction-based approach eliminates the need for routing area estimation and guarantees high density.

**Symmetric routing for net bundles** -- Addresses the problem that in bundled nets (common in both analog and digital), corners cause **net length differences** and aggressors affect individual nets in the bundle differently. The methodology minimizes these effects through proper routing area selection, adding extra routing paths and adjustment sections if necessary.

**Two-step channel-based routing** (refs [73, 74]):
1. **Global routing**: module connections are projected onto the enclosing routing channel; the problem reduces to connecting points on an intersection grid. Uses an iterative maze router with **backtracking** (exhaustive but pruned by performance bounds). At this stage, node-to-node and node-to-ground capacitances can be predicted and their effect on performance calculated via sensitivity information.
2. **Local/detailed routing**: global information is mapped onto channels via four basic operations:
   - **Push** -- insert a connection into the channel
   - **Propagate** -- extend to the next connection point
   - **Peak** -- redirect the connection
   - **Pop** -- permanently direct out
3. **Final routing** uses a **switchbox routing** scheme: switchboxes are inserted at each level transition in the channel. Typical switchbox size does not exceed 3x3, keeping computation tractable. Local routing also uses backtracking-based exhaustive search.

### 4.5.6 Template-Based Approaches

Template-based routing addresses a fundamental practical concern: **analog designers prefer control** over the layout process and are skeptical of fully automatic tools. Templates also enable **technology porting** (migrating layouts between technologies) and **incremental design changes** without regenerating layouts from scratch.

**Core idea**: capture an expert designer's placement and routing knowledge in a reusable template, then transform it for new device parameters or technologies via compaction.

**Key systems:**

- **Sample layout template** (earliest proposal) -- Takes a template layout, required electrical parameters, and a geometrical constraint (e.g., aspect ratio). Uses exhaustive floorplan area optimization to determine optimal device shapes, then generates layout via **compaction** of the template with substituted devices. Routing remains intact; only interconnection lengths are stretched/compacted to fit new module sizes.

- **BALLISTIC** -- A layout language where interconnections are described via relative wiring commands specifying layers and breakpoints. Technology-portable; a few hundred lines suffice for medium-complexity analog cells. Code is translated to commercial design tool format.

- **CAIRO** -- A documented superset of C functions (not a special language). Layout code is compiled to generate the layout. Routing functions use **predefined reference points** for relative routing description, yielding shape-independent routing.

- **Retargeting methodology** (refs [79, 80]) -- Relies on existing block netlists, layout templates, and optional design constraints. Uses **deep hierarchical decomposition**: parameterized templates are built bottom-up from single devices to matching transistor sets to subcells to full blocks. Parameterization covers relative positions, interconnections, design rules, and **current densities**.

- **LAYGEN** -- Two-stage template-based routing:
  1. **Adjustment**: template routing paths are scaled and repositioned to match new pin positions (scale, move start point, set stop point)
  2. **Evolutionary optimization**: a genetic optimizer minimizes a cost function incorporating design rule violations, connectivity, wire length (for parasitic capacitance), and inter-net distance (for crosstalk). Each net is encoded as one gene; crossover combines parent nets, and mutation operates per-net with "intelligent" operators that leverage routing information.

#### 4.5.6.1 Layout Description Script (LDS)

**LDS** is a simple template scripting system based on equations defining absolute or relative positions of layout elements (modules, wires, wells) using their **top, bottom, right, left boundaries**.

Key properties:
- No redundant information; each code line contains only horizontal or vertical info (never both)
- Extracted from placement using **horizontal and vertical constraint graphs**
  - Simple graph: edges from right boundary of one element to left boundary of another visible element
  - **Extended graph**: adds edges to prevent overlap when elements are resized -- edges connect right boundary to left boundary of elements with higher x-positions and no intervening elements
- **Overlap prevention**: the extended constraint graph guarantees non-overlapping layouts for any element sizes. Compaction removes extra space after resizing.
- **Design rule handling**: constraints are extracted per-layer, considering only elements in the same layer belonging to different nets (same-net wires need no spacing)
- **Dynamic paths**: wires can be coded with flexible structures (using 4 wires instead of 3) so orientation can change freely without restricting horizontal/vertical positioning
- Constraints are solvable with an **LP (Linear Programming) solver**

### 4.5.7 Other Routing Strategies

**Probabilistic routing** -- Borrowed from digital routing to address wire congestion and net ordering effects:
- **Resistor array method** (ref [83]): global routes are assigned to routing areas between modules. A resistor array is created where each resistor represents a possible routing area; resistor values encode routing probability based on geometric and constraint information. The array is simulated and low-probability resistors are iteratively removed, updating probabilities until assignment is complete.
- **Grid-point probability method** (ref [84]): uses a heuristic converting probabilities to routing priorities. Probabilities are assigned to each grid point (finer granularity than the resistor array). The probability formulation accounts for analog constraints including **symmetry**.

**X-Y routing with candidate generation** (ref [85]) -- A fundamentally different approach from incremental maze routing:
1. Two adjacent metal layers are routed simultaneously: all horizontal segments on one layer, all vertical on the other, connected through stacked vias
2. Routing proceeds in phases, each generating candidate routes with different numbers of vias
3. Multi-terminal nets are decomposed into two-terminal nets using a **minimal spanning tree** ($t-1$ edges for a $t$-terminal net)
4. Most candidates are generated within the **bounding box** (smallest rectilinear region containing all terminals)
5. A **compatibility graph** $G(V, E)$ is constructed: vertices = candidate routes, edges = incompatible route pairs
6. The graph is reduced to remove all edges, yielding a **reduced compatibility graph (RCG)** of mutually compatible candidates
7. One candidate per net is chosen from the RCG

This approach has an **inherent global perspective** -- it satisfies all constraints simultaneously for all nets, unlike incremental net-by-net approaches that may fail as congestion increases. It can be extended to **45-degree routing**.

**User-specifiable constraints** include: wire widths, layer confinement, keep-out areas, parallel distances, and coupled lengths between segments as a function of width.

## Algorithms & Methods

### A* Algorithm for Analog Routing

The A* algorithm is adapted from graph theory shortest-path computation for area routing. Its worst-case complexity is $O(n^2)$ (same as Lee-Moore), but average performance is much better due to heuristic guidance.

**Cost formulation:**

$$f(x) = g(x) + h(x)$$

where:
- $g(x)$ = cost from source $s$ to intermediate wire $x$ (actual parasitic cost accumulated)
- $h(x)$ = estimated minimum cost from $x$ to target $t$ (must not overestimate; Manhattan distance is a common heuristic)

**Parasitic-aware cost** (resistive + capacitive):

$$g(x) = \mathbf{A} \cdot (\mathbf{G}_{x-1} + \Delta\mathbf{G}_x)$$

where $\mathbf{A}$ is the performance weight vector, $\mathbf{G}_{x-1}$ is the accumulated performance metric vector, and $\Delta\mathbf{G}_x$ accounts for additional capacitances $C_{ij}$ between nets and additional resistance $R$.

**Data structure**: $\{f(x), x\}$ pairs stored in a **red-black tree** with linked lists to handle duplicate $f(x)$ values -- the tree nodes point to linked lists of vertices sharing the same cost.

**Pseudocode** (see Fig. 4.21):
1. Initialize: place source in open-set with $f = h(\text{source})$
2. Loop while open-set is not empty:
   a. Extract vertex $x$ with minimum $f(x)$
   b. If $x$ is in closed-set, skip
   c. For each neighbor $y$ of $x$ not in closed-set:
      - Compute $g(y)$ and $h(y)$
      - Set $f(y) = g(y) + h(y)$
      - Add $\{f(y), y\}$ to open-set with backpointer to $x$
   d. Add $x$ to closed-set
3. Reconstruct path by following backpointers from target to source

### ALADIN Two-Phase Routing

1. **Global routing**: build channel intersection graph; solve minimum-Steiner-tree via Dijkstra; integrate with placement iteration
2. **Detailed routing**: order modules (symmetric/central first); ring-route within each module; compact modules together; maze-route inter-module connections

### LAYGEN Template-Based Routing

1. **Scale** template paths to new placement dimensions
2. **Translate** wire start points to new pin positions
3. **Adjust** wire stop points for connectivity
4. **Optimize** using genetic algorithm with per-net gene encoding

### X-Y Routing with Compatibility Graphs

1. Generate candidate routes phase-by-phase (varying via counts)
2. Build compatibility graph $G(V, E)$ from candidate conflicts
3. Reduce graph to remove all incompatibilities
4. Select one compatible candidate per net from RCG

## Connections to Bigger Picture

This sub-chapter covers the most sophisticated routing strategies in analog layout synthesis, progressing from the idea that placement and routing should not be treated independently (Section 4.5.4) to the practical need for designer-controlled template-based approaches (Section 4.5.6). The integrated placement-and-routing systems like KOAN/ANAGRAM II and GELSA represent a paradigm shift from the sequential digital-inspired flow described in [[4.4 Routing Issues for Analog Circuits]], acknowledging that analog circuits' sensitivity to parasitics demands tighter coupling between these stages. The template-based approaches in Section 4.5.6 reflect a pragmatic recognition that full automation is not always desired or optimal -- they connect to the broader theme in the book that analog layout synthesis must balance automation with designer expertise. Section 4.5.7's probabilistic and candidate-generation methods offer alternatives to the maze-routing paradigm that dominates [[4.4 Routing Issues for Analog Circuits|earlier sections]], providing global optimization perspectives. These advanced strategies set the stage for [[4.6 Specialized Routers and Manufacturability]], which addresses domain-specific routing (RF, analog arrays) and yield-aware routing.
