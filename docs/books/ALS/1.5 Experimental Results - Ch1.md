# 1.5 Experimental Results - Ch1

> **Chapter 1**: Device-Level Topological Placement with Symmetry Constraints (Florin Balasa)
> **Part**: Part I: Placement

This note covers Section 1.5 (Experimental Results) and Section 1.6 (Conclusions) of Chapter 1, which validate the topological placement algorithms developed in the preceding sections through benchmark experiments and summarize the chapter's contributions.

## Key Concepts

### 1.5 Experimental Results

A prototype placement tool for analog layout was implemented in **C++** with the following characteristics:

- **Optimization engine**: Simulated annealing (SA) with selectable exploration algorithms
- **Controlled comparison**: The cost function, SA cooling schedule, and inner-loop criterion were kept **identical** across all tested placement algorithms to ensure fair evaluation
- **Topological representations supported**:
  - [[1.3 Symmetric-Feasible Sequence-Pairs|Sequence-pairs]]
  - [[1.4 Topological Placement with Symmetry Constraints|Binary trees]]
- **Code evaluation algorithms**: Multiple options using the data structures from [[1.2 Data Structures for Rectilinear Border Contours|Section 1.2]] (segment trees, red-black interval trees, deterministic skip lists, priority queues)
- **Constraint handling**:
  - Symmetry constraints (single and multiple symmetry groups)
  - Systematically-induced device mismatches
  - Alignment constraints
  - Shape optimization for parametric cells and "soft" cells (e.g., capacitors with continuously varying aspect ratios)
- A complementary placement algorithm based on the **traditional absolute representation** was also embedded for baseline comparison

### Benchmark Circuits

### Key Experimental Findings

1. **Evaluation algorithm speed comparison**:
   - **Priority queues** (Sect. 1.3.1) are the fastest evaluation method
   - **Red-black interval trees** and **deterministic skip lists** ([[1.2 Data Structures for Rectilinear Border Contours|Sects. 1.2.2 and 1.2.3]]) are almost as fast as priority queues
   - **Segment trees** ([[1.2 Data Structures for Rectilinear Border Contours|Sect. 1.2.1]]) are the slowest, though the differences are not very significant

2. **Binary trees vs. sequence-pairs**:
   - Binary tree exploration is **typically faster** than sequence-pair exploration
   - However, **layout quality tends to be poorer** with binary trees
   - The speed advantage is expected because the solution space of binary tree representations is always **smaller** than that of sequence-pairs, for any placement problem (with or without symmetry constraints)
   - Layout quality depends on the move set and how **uniformly** the solution space is explored; sequence-pair-based algorithms appear to explore the space more effectively

3. **Impact of symmetry constraints on runtime**:
   - Running times with symmetry groups are **higher** than those of other topological tools operating without symmetry (e.g., FAST-SP)
   - This overhead comes from: (a) moves for cells in symmetry groups being **several times more computationally expensive**, and (b) **more traversals** of the topological representation required
   - Despite the cost, restricting moves to the subset of **symmetric-feasible codes** is **significantly better** than exploring the entire (unconstrained) solution space

4. **Topological vs. absolute representations**:
   - **All** techniques exploring symmetric-feasible topological representations exhibit **significantly better performance** than the traditional absolute representation
   - The advantage holds at least in computational effort, and sometimes also in placement quality
   - The simulated annealing optimizer is **easier to tune** when using topological representations

### 1.6 Conclusions

The chapter concludes by summarizing its core contribution: the use of **non-slicing topological representations** (sequence-pairs and binary trees) with **built-in symmetry constraints** for analog placement, as an alternative to the traditional absolute-coordinate approach with SA. The key insight is that symmetry constraints -- which are ubiquitous in analog design -- should be **directly embedded** into the representation's exploration strategy rather than handled as post-hoc penalties or repair operations.

## Algorithms & Methods

No new algorithms are introduced in Sections 1.5--1.6. Instead, these sections provide the **empirical validation** of the algorithms developed earlier in the chapter:

- **Sequence-pair based placement** with symmetric-feasibility ([[1.3 Symmetric-Feasible Sequence-Pairs]])
- **Binary tree based placement** with symmetric-feasibility ([[1.4 Topological Placement with Symmetry Constraints]])
- **Evaluation algorithms** using four different data structures ([[1.2 Data Structures for Rectilinear Border Contours]]):
  1. Segment trees -- $O(n \log n)$ per evaluation
  2. Red-black interval trees -- $O(n \log n)$ per evaluation
  3. Deterministic skip lists -- $O(n \log n)$ per evaluation
  4. Priority queues -- fastest in practice

The experimental methodology is itself noteworthy: by fixing the **cost function**, **cooling schedule**, and **inner-loop criterion** across all algorithms, the comparison isolates the effect of the topological representation and evaluation data structure, controlling for the SA engine's behavior.

## Connections to Bigger Picture

This section serves as the empirical capstone for Chapter 1, validating that topological placement with embedded symmetry constraints is superior to absolute-coordinate approaches for analog layout. The benchmarks range from small amplifiers (17 cells) to complex transceiver blocks (116 cells with five symmetry groups), demonstrating scalability of the approach. The finding that sequence-pairs yield better layout quality while binary trees are faster provides practical guidance for tool implementers. These results set the stage for [[2.1 Introduction to Hierarchical Placement|Chapter 2]], which extends the placement problem to hierarchical structures -- a natural next step for handling the larger analog systems where flat placement becomes intractable. The comparison framework established here (controlled SA parameters, multiple representations) also provides a methodological template that later chapters implicitly follow.
