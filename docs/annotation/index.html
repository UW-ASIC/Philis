Netlist Annotation — pnr-annotation

Automatic circuit recognition and constraint extraction. Takes a flat SPICE-derived hypergraph, identifies known analog blocks (diff pairs, mirrors, cascodes, arrays), groups them into hierarchy levels, and emits layout constraints (symmetry, matching, common-centroid) that drive placement and routing.

Key mechanism: BipartiteHypergraph::group() already exists. It collapses N device cells into one macro node, rewires pins, and rebuilds the CSR. Annotation is a series of group() calls + ConstraintRecord population.

Annotation Stages

S2 Preprocess & Canonicalize

Normalize the flat graph before matching. Merge parallel devices (same type, same terminals) into one node with accumulated multiplicity. Tag VDD/VSS/ground/clock nets from names or user directives. These nets are excluded from symmetry pairing and template matching (everything connects to them → false matches).

S4 Exact Subgraph Match — Reduce & Replace

Core algorithm. For each template in the library (largest/most-specific first): run labeled subgraph isomorphism (VF2 with node/edge match predicates on device type, terminal pin, net role). On match → hg.group() contracts matched nodes into one macro cell. Repeat until fixpoint. Bottom-up: primitives first, then higher-level blocks match on the reduced graph. 

while changed:
    for template in order_library(library):  // largest first
        for mapping in subgraph_iso(G, template):
            if violates(user_constraints, mapping): continue
            hg.group(name, template.name, matched_instances)
            constraints += template.implied_constraints
            changed = true
            break  // re-scan reduced graph

S5 Array / Repeated-Structure Detection

Binary-weighted cap banks, R-2R ladders, mirror banks. Find a candidate unit, search for iso/approx-iso repeats with regular connectivity. Wrap in array block + common-centroid constraint. Uses GED oracle (S6) for approximate matches.

S6 GNN Approximate Match (GANA)

GCN node classification for module-level blocks (OTA, LNA, Mixer variants). Post-process: connected-component cleanup → group. Siamese GED-GNN for "are these two sub-structures the same?" — oracle for array detection and symmetry. Implement last — exact matcher handles most structure.

S7 Symmetry & Constraint Generation

For each recognized block: find symmetric pairs (graph-based matching or GED oracle), self-symmetric elements, hierarchical nesting of axes. Emit:

  • SymmetryGroup — axis + pairs + self-symmetric devices
  • MatchingPair — devices that must be laid out identically
  • ParasiticBudget — per-net R/C budgets from recognized critical paths

Integration with flow.rs

Current state

// flow.rs:242 — today
let g = parse_spice(spice, &pdk, &HashSet::new())?;

// flow.rs:157 — macros hit this error
"cell `{}` is a macro; macro geometry not wired into the flow yet"

After annotation

let mut g = parse_spice(spice, &pdk, &HashSet::new())?;

// NEW: annotation pass — group recognized blocks, populate constraints
let rec = pnr_annotation::annotate(&mut g, &library, user_constraints)?;

// generate_cells now handles grouped macros via CellRegistry
let gen = generate_cells(&g, &pdk, &deck, &registry)?;
Each annotated group = one macro cell node in the hypergraph. CellRegistry custom entries provide generators for these groups. flow.rs treats them identically to substrate3-implemented cells — no special casing needed downstream.
