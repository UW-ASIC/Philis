What this book changes about the meaning of a good layout

Helmut E. Graeb, Analog Design Centering and Sizing (2007), supplies the statistical and optimization foundation needed to turn a geometrically attractive placement into an electrically robust design. Its central distinction is between meeting specifications at one nominal point, surviving a prescribed uncertainty region, and maximizing the probability that manufactured circuits satisfy all specifications under all required operating conditions. Those are different objectives. A small, symmetric layout can perform worse on the last two even when its nominal simulation is better.

Source finding: design centering means yield optimization in parameter space. It is unrelated to putting devices at the geometric center of a floorplan. Common-centroid placement can improve one physical contributor to yield, but is not itself design centering. The book makes the distinction even between centering performance values, inscribing the largest tolerance ellipsoid, and maximizing actual probability mass. PDF pp. 89–99, pp. 164–166, p. 179.

Proposed engine consequence: store nominal performance, robust margins, statistical assumptions, and estimation confidence separately. An optimizer may use a cheap robustness proxy, but its report should name the proxy rather than relabel it yield. The reason is practical: the user must know whether a better score means less wire, larger simulated phase margin, a larger modeled failure distance, or measured improvement in joint passing probability.

Three parameter classes, three different responsibilities

The book writes performance as f(xd, xs, xr). Design parameters xd are quantities the designer controls: device dimensions, bias choices and, in a layout extension, legal placement coordinates, fingers, topology, widths and contacts. Statistical parameters xs represent manufacturing variation and have a probability model. Range parameters xr represent operating conditions such as supply and temperature; their specified ranges must be covered, and a probability distribution need not exist. Treating range parameters as convenient random variables silently changes the specification. PDF pp. 46–50.

Action and reason: define a scenario as a combination of an operating condition and a process/mismatch realization, with separate provenance for each. This prevents a Monte Carlo run dominated by room-temperature samples from claiming compliance over a full temperature range. Discrete PDK corner names should remain named model scenarios; they are not automatically independent Gaussian dimensions and do not by themselves define a yield distribution.

The introductory circuit uses normalized parameters with time constant τ = RC and illustrative area A = R + C. Centering the allowed time-constant interval [0.5, 2] gives τ = 1.25; minimum illustrative area then gives R = C = √1.25. Centering the feasible segment along R = C instead gives R = C = (√0.5 + √2)/2 and τ = 1.125. Unequal R and C standard deviations change the yield optimum again. This is a pedagogical normalized model, not a physical claim that resistance and capacitance can be added to obtain silicon area. PDF pp. 38–44.

Validation: preserve such a tiny analytic model as an independent optimization oracle. A robustness implementation should distinguish these three solutions, preserve the parameter units, and reproduce an independently integrated yield. This tests the meaning of the objective rather than merely duplicating an optimizer's arithmetic.

Covariance is part of the physical model

For mean μ and positive-definite covariance C, a multivariate Gaussian has equidensity contours characterized by squared distance β² = (xs − μ)ᵀC⁻¹(xs − μ). With diagonal standard-deviation matrix D and correlation matrix R, C = DRD. A factorization C = AAᵀ allows samples xs = μ + Az with independent standard-normal components in z. Whitening also makes numerical distances meaningful when parameters have different units. PDF pp. 51–63.

Global and local variations must remain separate. A global threshold perturbation shared by two matched transistors largely cancels in their difference; independent local threshold errors do not. Under a simple model q1 = μ1 + g + l1, q2 = μ2 + g + l2, independent local terms with variance σl² give Var(q1 − q2) = 2σl². Counting g independently twice destroys that cancellation. Conversely, assuming every local effect is independent discards spatial correlations. The book introduces global/local decomposition; the exact decomposition used by an engine must come from the PDK or a calibrated model. PDF pp. 63–64.

Proposed action: let placement-dependent mismatch models produce covariance terms, not only one penalty per pair. Propagate them into each sensitive circuit output using Cov(f) ≈ S C Sᵀ. This preserves cancellation and reinforcement shared across constraints. The approximation assumes a valid local linear response and a covariance model appropriate to the layout and bias; final nonlinear simulation must check critical outputs.

Numerical safeguards: covariance diagonal entries are variances, not standard deviations. Check symmetry and positive semidefiniteness; pairwise correlation magnitudes below one are insufficient for a valid matrix in three or more dimensions. If C is singular because quantities are exactly shared, sample its nonzero-rank subspace instead of blindly taking an inverse. A nonlinear transformation to Gaussian latent variables changes derivatives and, for density calculations, requires the appropriate Jacobian.

Sensitivities, scaling and what the optimizer should improve

A local sensitivity matrix has entries Sij = ∂fi/∂xj, giving Δf ≈ SΔx. Rows describe how one output responds to all parameters; columns describe one parameter's effects on all outputs. The book uses these directions to discuss similarity, significance and adjustability. Their numerical lengths and angles are meaningful only after defining parameter and performance scales. Changing nanometers to micrometers must not alter which transistor appears important. PDF pp. 68–75.

For a finite-difference sensitivity, too small a perturbation exposes simulator tolerances; too large a perturbation averages nonlinear behavior. Therefore attach a perturbation size, operating point, extraction version and consistency check to every derivative. Central differences can expose asymmetry but cost additional simulations. A gradient cannot justify an unlimited move: maximizing a linear improvement without a step bound is unbounded. Use a domain or trust region.

Pareto dominance compares a complete objective vector: one candidate dominates another only if it is no worse in every retained objective and strictly better in at least one. Weighted sums can miss unsupported portions of nonconvex fronts. Min-max or target-based formulations can explore other compromises, but their weights and reference points still encode user preferences. A zero-weight objective can permit weakly Pareto solutions; retain tie-breaking and dominance checks. PDF pp. 75–83.

Engine mapping: Philis already distinguishes hard constraints, budgets and costs in Requirements<On> (line 18). That is useful infrastructure for avoiding a single uninterpretable score. The geometric finite differences in gradient computations around lines 205–221 differentiate the current placement objective; they are not transistor-to-circuit performance sensitivities. Add a separately identified circuit-response model rather than relabeling the existing derivative.

Three worst-case analyses, with explicit assumptions

Box case. Let f ≈ f0 + gᵀδ and independent bounded coordinates satisfy |δk| ≤ ak. Then the upper linear worst case is f0 + Σ|gk|ak; choose δk = ak sign(gk). The lower case changes the sign. This is appropriate for a specified independent tolerance box and exact for a linear response. If gk = 0, that coordinate is undetermined to first order; it is not proven irrelevant to a nonlinear circuit. PDF pp. 103–108.

Ellipsoid case. For δᵀC⁻¹δ ≤ β² and σf = √(gᵀCg), the linear extrema are:

fupper/lower = f0 ± βσf
δupper/lower = ±β Cg / σf

The equations follow by transforming δ = Az and applying Cauchy–Schwarz to gᵀAz with ||z|| ≤ β. They require σf > 0; otherwise the linear model predicts no variation and a higher-order check is needed. These equations were verified against the rendered source. PDF p. 111.

Nonlinear case. Optimize the real response over the statistical region and operating range. Different specifications generally have different worst-case points; an interior operating point can be worse than all corners. Mismatch can produce multiple opposite failure directions. A single start of an SQP solver is not a global certificate. The book explicitly discusses these difficulties and the nested cost of worst-case analysis. PDF pp. 87–89, pp. 113–124, pp. 147–153.

Checked correction: the nonlinear Lagrangian in §5.4, Eq. (189), PDF p. 115 has Hessian ∇²f + 2λC⁻¹, not merely 2λC⁻¹ as stated in the following paragraph. Positive definiteness of C does not establish second-order sufficiency for an arbitrary nonlinear response. Appendix C.6, Eq. (C.24), PDF p. 195 correctly includes objective and constraint curvature. Never convert that paragraph into a solver acceptance test.

Yield is a joint event, not a collection of good-looking margins

Y(xd) = Prxs[for every xr in Tr: fL ≤ f(xd, xs, xr) ≤ fU].

One sample passes only if every specified feature passes throughout the required operating domain. A gain pass probability and a phase-margin pass probability are yield partitions. Their minimum is an upper bound on joint yield; multiplying them is justified only with independence. Because the same devices and parasitics influence both outputs, independence is usually a modeling assumption to test, not a default. PDF pp. 89–96.

A β = 3 statement needs a region definition. For one linear upper-bounded Gaussian output it corresponds to Φ(3), about 99.865% passing. For a symmetric interval on that output it gives 2Φ(3) − 1. For an n-dimensional Gaussian ellipsoid of radius β, enclosed probability is Pr[χ²n ≤ β²], not Φ(β). The book's table shows that a radius-three ellipsoid encloses about 46.8% in ten dimensions. There is no contradiction: a half-space and a ball are different events. PDF pp. 133–145.

Geometric yield analysis finds the nearest failure boundary in whitened coordinates. Linearizing that boundary at its most probable point gives a half-space approximation and a signed distance: positive for nominally passing, negative for nominally failing. This is more informative than nominal slack alone because it divides a performance margin by sensitivity to variation. However, curved or disconnected boundaries and multiple failure regions can invalidate a single tangent approximation. The book's 1–3% empirical approximation discussion is historical experience, not a guaranteed error bound for Philis or a justification for ppm certification. PDF pp. 146–160.

Action: use the smallest signed failure distance to identify the current bottleneck, retain all active failure modes, then estimate joint yield from their shared latent variables. For finalists, compare this approximation with circuit-based sampling. This directs computation toward the failure boundary without treating the approximation as independent evidence.

Monte Carlo accuracy and rare failures

With N independent process samples and K passing samples, Ŷ = K/N. For Bernoulli pass events, Var(Ŷ) = Y(1−Y)/N. The variance depends directly on sample count and yield, while the cost per sample still depends on circuit size, parameter count and operating checks. Accuracy improving like 1/√N explains why a visually convincing handful of simulations cannot validate high yield. PDF pp. 125–133.

A normal confidence approximation is useful away from extreme probabilities and with enough observed successes and failures. It is misleading at zero observed failures: substituting Ŷ = 1 into a variance estimate gives zero, but the underlying failure probability remains uncertain. As an independent derivation, zero failures in N independent trials has probability (1−p)ᴺ. A one-sided 95% upper bound is therefore pupper = 1 − 0.05^(1/N), approximately 3/N. One thousand clean samples support only an upper failure bound near 0.3%, under the model and independence assumptions.

The book's importance-sampling estimator reweights draws from a proposal q by p/q. A proposal must cover all relevant failure support; otherwise omitted failure modes create bias. For rare failures, estimating failure probability directly can be more stable than subtracting a yield estimate from one. Record weights, effective sample behavior and the proposal. A variance formula for unweighted Bernoulli samples cannot be reused unchanged for weighted samples. PDF pp. 127–132.

Validation contract: distinguish optimizer training samples from independent final validation samples; preserve seeds and model hashes; report confidence bounds, scenario coverage and unresolved simulation failures. Failed convergence is an unknown result requiring treatment, not an automatic pass. Common random numbers may help compare nearby designs but do not make correlated comparisons independent validation trials.

How the design should move

For fixed Gaussian covariance and a fixed acceptance region, the book derives the mean-shift yield gradient ∇μY = YC⁻¹(μaccepted − μ). This explains the term centering: at an unconstrained stationary point with positive yield, the accepted population's mean matches the manufactured population's mean. It is not a sufficient global optimality condition. More importantly, transistor width, routing topology or finger count generally changes the acceptance region and may change covariance; the formula cannot be applied to those design variables as if they simply shifted a process distribution. PDF pp. 162–170.

The geometric alternative improves signed worst-case distances. A min-max formulation maximizes the weakest distance; a target least-squares formulation balances distances against chosen goals. This can deliberately trade nominal bandwidth for better weak metrics. The source op-amp example raises the minimum distance from 1.1 to 3.9 while reducing nominal transit frequency; it illustrates robust tradeoffs, not an engine-independent guarantee. PDF pp. 173–180.

For a local residual vector e and Jacobian J, the regularized least-squares step solves (JᵀJ + λI)r = −Jᵀe. The transpose on the right is essential; §7.2.3 defines gradients as rows in Eq. (362), but printed Eqs. (365) and (368) on PDF p. 176 omit the right-hand transpose. This is a dimensionally checked correction confirmed against the rendered page. Use numerically stable QR/SVD or an appropriate solver rather than blindly forming normal equations when conditioning is poor. Verify predicted improvement by re-evaluating the true response and shrink the trust region if agreement deteriorates. This prevents large geometry moves from exploiting an obsolete local model. PDF pp. 175–179.

For very high yield, raw Y becomes a flat objective. The book proposes tolerance inflation or distance optimization to expose remaining robustness. Inflation is an optimization aid: results must finally be evaluated under the original process distribution. Layout cannot arbitrarily tune a foundry covariance matrix; any tolerance-assignment variable must correspond to an allowed physical choice such as area, spacing, device class or purchased process option.

Concrete integration sequence and meaningful checks

  1. Represent electrical specifications before adding more weights. Store metric, bound, units, corner/range quantifier and response model. This makes it possible to distinguish an actual performance constraint from a heuristic geometric preference.
  2. Extend existing wire budgets into traceable performance reductions. The generic ParasiticBudget::extract helper has a default length budget, while the active annotator already derives lengths from class/load-based capacitance allowances and process wire capacitance. Preserve that path and its assumptions, add circuit sensitivities and available performance margin where characterized, and revise estimates with extracted electrical results. The book does not justify one universal maximum net length.
  3. Attach covariance and scenario context to matching budgets. placement (line 53) emits topology-based matching, proximity and thermal requirements. Keep this useful structural inference, but record which uncertainty terms each rule addresses and calibrate numerical thresholds to actual models.
  4. Use a staged fidelity loop. Cheap geometric screening, local response estimates, selected extraction/simulation, and independent final yield checks have different jobs. Refit when topology, device variants or active operating conditions change, because those changes can invalidate derivatives discontinuously.
  5. Prove numerical meaning with analytic cases. Check Gaussian linear propagation against gᵀCg, box extrema against enumeration, singular shared variation against reduced-rank sampling, and nonlinear functions with known interior or dual failure points. Compare candidate ranking with actual post-layout simulation before increasing optimizer complexity.

These are proposed extensions, not claims that Philis currently performs statistical circuit optimization. The book provides the objective definitions and mathematical checks needed to build that capability without confusing a geometry score with measured robustness.
