Robust design, variation and yield

Separate corners, statistical parameters, joint yield and design-centering approximations.

Optimize a manufactured population under a defined operating contract

A robust layout protects electrical behavior when fabrication and operating conditions depart from nominal. This requires more than a process-corner pass, more than matching geometry, and more than a large nominal margin. Define the random variables, required operating domain and complete acceptance event before choosing a robustness score. Otherwise the optimizer can improve a number that does not answer the user's engineering question.

Graeb distinguishes design variables xd, statistical fabrication variables xs, and range variables xr such as supply and temperature. The yield contract is:

Y(xd) = Prxs[∀ xr ∈ Tr: every specified lower and upper performance bound passes].

A statistical draw describes a manufactured instance; that same instance must work throughout the specified operating domain. Randomly choosing one temperature per manufactured sample answers a different question. Similarly, checking a few named process corners does not define a probability distribution or quantify local mismatch. These analyses can complement each other, but their results need separate labels. Design Centering, PDF pp. 46–50, pp. 89–95.

Design centering means adjusting controllable design choices to improve this probability. It is not geometric centering of devices. Common-centroid placement is one technique that may improve selected mismatch mechanisms; its value is established by how it changes the circuit's acceptance region and uncertainty model.

Global process, local mismatch and spatial fields are different models

For a simple matched pair, write q1 = μ1 + g + l1 and q2 = μ2 + g + l2. Here g is a shared die-level variation and l1, l2 are local deviations. Subtracting gives q1 − q2 = μ1 − μ2 + l1 − l2; the shared term cancels exactly in this parameter difference. If σg = 20 mV and independent local σl = 3 mV, each device has standard deviation √409 ≈ 20.22 mV, but the difference has standard deviation √18 ≈ 4.24 mV. Treating the device totals as independent would predict about 28.6 mV and lose the cancellation.

This cancellation is conditional. An actual current difference may have unequal sensitivities to the shared parameter because the devices differ in geometry, bias or temperature. Propagate the full circuit response rather than assuming every globally varying quantity cancels in every matched output. The book introduces shared and local parameter spaces as a modeling foundation; PDK definitions determine the real decomposition. PDF pp. 63–64.

A spatial field adds another structure: a slowly varying process or temperature field is sampled at each unit's location. Derived moment condition: for a difference of weighted responses, cancellation of a common affine spatial field requires equal zeroth and first moments of the comparison weights. For ratio matching, normalize each group's weights by its intended total before comparing centroids; raw unit counts need not be equal. This conclusion assumes the same local field and linear response coefficient for the compared unit contributions. It does not cancel arbitrary second-order fields, unequal edge environments or a routing-induced bias difference. Random area-dependent mismatch also remains. The physical action follows from the mechanism: use larger matched units to reduce a calibrated random term, spatial arrangement for appropriate gradients, and equivalent surroundings or routing for other systematic terms. Do not use one spacing penalty as a universal replacement for all of them. Lampaert, PDF pp. 53–55.

Build a valid covariance model before propagating it

Let Cij = Cov(xi, xj), with diagonal entries σi². A valid covariance matrix is symmetric positive semidefinite. Pairwise correlation magnitudes below one do not suffice: for three unit-variance variables with all pairwise correlations −0.9, the vector (1,1,1) has negative quadratic variance, so the matrix is impossible. Test the matrix as a whole.

For Gaussian variables, a factorization C = AAᵀ supports samples x = μ + Az with independent standard normal z. Exact common variables can make C singular; use a reduced-rank factorization. When parameters have positive support or non-Gaussian distributions, a latent normal transformation may be useful, but its validity and transformed sensitivities must be established. Correlation does not specify the whole joint distribution outside the Gaussian case. Design Centering, PDF pp. 51–63.

For locally linear outputs f ≈ f0 + S(x − μ), propagation gives Cov(f) ≈ S C Sᵀ. The off-diagonal output terms matter because yield requires simultaneous success. Computing one standard deviation per performance metric discards the dependence needed for a joint pass probability. Attach covariance to stable device and latent-variable identities, so flattening or merging fingers does not redraw shared global variation independently.

Action: require every statistical model to declare population scope, units, supported device types, bias and temperature domain, geometry dependence and correlation structure. Cache it against layout and PDK revisions. This protects the optimizer from improving a layout under a stale covariance model after area, spacing or unit count changes.

Worst-case distance measures margin relative to sensitivity

For one upper-bounded linear Gaussian metric f = f0 + gᵀδ, its standard deviation is σf = √(gᵀCg). Define signed margin distance β = (U − f0)/σf. A positive β means nominally passing; a negative β means nominally failing. The exact one-bound pass probability in this linear Gaussian model is Φ(β). For a lower bound, use β = (f0 − L)/σf. Zero σf requires separate deterministic or higher-order treatment rather than division by zero.

A nominal margin of 10 mV with σ = 5 mV gives β = 2. A smaller 8 mV margin with σ = 2 mV gives β = 4. The second design is much more robust to that modeled variation despite its smaller nominal headroom. This is why a layout change that slightly worsens nominal gain can still be valuable if it reduces sensitivity or mismatch enough. Design Centering, PDF pp. 111–112, pp. 154–158.

For nonlinear metrics, find the nearest failure boundary in whitened variables z: minimize ||z|| subject to reaching the specified bound, with operating conditions chosen according to the worst-case contract. Linearization at that point gives a local probability approximation. Multiple failure surfaces, two-sided mismatch failures and interior operating extrema require multiple starts or other search mechanisms. A nominal sensitivity of zero can hide a quadratic failure mechanism; it does not prove immunity.

Minimizing over supply and temperature is nested inside the acceptance event. If a response is proven monotone over the specified range, its worst case is at a boundary; otherwise a corner-only scan can miss an interior failure. Store evidence for monotonicity or report the actual sampled domain. The book explicitly distinguishes box-linear, ellipsoid-linear and general nonlinear worst-case analyses. PDF pp. 103–124, pp. 148–153.

Why “three sigma” needs a complete sentence

For n independent standardized Gaussian variables, a radius-β ball has probability Pr[χ²n ≤ β²]. A symmetric ±β box has probability [2Φ(β) − 1]ⁿ. A single normalized linear upper bound has probability Φ(β), independently of the number of underlying Gaussian variables because the projection is one dimensional. These are different regions, so their different probabilities are expected. The source's tolerance-class chapter derives the distinction directly. Design Centering, PDF pp. 133–145.

Joint circuit yield is the probability of the intersection of all acceptance regions. Its value is at most the smallest individual pass probability. A union bound gives a conservative lower bound Y ≥ 1 − Σj Pr(failure j), clipped to zero; independence is not required. Multiplying pass probabilities needs independence and should not be the default for several responses of the same circuit.

Maximizing the minimum β is a useful bottleneck objective but does not exactly maximize joint yield. For two independent one-sided linear metrics, β = (3,3) gives joint yield about 0.997302. β = (2.9,8) gives about 0.998134, even though its minimum distance is smaller. The best objective depends on whether the contract prioritizes the weakest margin, actual joint probability, or another explicit preference. The source makes the distinction between maximal inscribed tolerance regions and exact design centering. PDF pp. 179–180.

Validate yield with an uncertainty statement

Ordinary Monte Carlo draws independent manufactured instances and evaluates the complete acceptance event. For K passes in N draws, Ŷ = K/N and Var(Ŷ) = Y(1−Y)/N. Increasing accuracy by a factor of ten requires roughly a hundred times as many samples at fixed yield. The dimensionality does not appear directly in this Bernoulli variance formula, but circuit simulation and operating-domain verification still become more expensive with problem complexity. PDF pp. 125–133.

Zero observed failures is not a perfect-yield certificate. Under independent draws, Pr(no failures | p) = (1−p)ᴺ. Equating this to 0.05 yields a one-sided 95% upper bound pupper = 1 − 0.05^(1/N). At N = 3000, it is about 0.1%. Demonstrating a one-part-per-million upper bound this way requires roughly three million clean samples. This is a derivation of estimator limits, not a demand to run that many samples for every exploratory layout.

Use a hierarchy of evidence. Cheap linear models screen moves. Geometric failure searches find likely failure regions. Importance sampling draws more frequently near failures and reweights by true density divided by proposal density. Independent finalist validation checks the model and estimator assumptions. An importance proposal must cover all important failure modes; a narrow proposal around one mismatch direction can miss the opposite direction. Weighted samples require weighted variance analysis, not the ordinary Bernoulli formula. PDF pp. 127–132.

Record simulator nonconvergence and invalid operating points explicitly. They are unresolved outcomes until a defined analysis determines their status. Keep optimization samples separate from held-out validation; repeatedly choosing the best candidate using the same small sample can overfit the sample noise. Common random draws are useful for paired comparisons, but they do not make multiple reused comparisons independent experiments.

Make physical design choices that change the failure mechanism

When offset yield is poor, determine whether the dominant cause is random local variation, a systematic spatial field, unequal electrical environment, or bias sensitivity. Larger unit area can reduce calibrated random mismatch while increasing parasitic capacitance. Closer placement can help spatial matching while creating congestion or thermal interaction. A common-centroid arrangement may improve a gradient term while lengthening sensitive cross-connections. Every action therefore needs both an intended mechanism and a post-layout check of its competing effects.

The source's geometric optimization example improves the weakest margins while allowing strong nominal metrics to degrade. Its trust-region method controls the size of changes because local response models eventually become inaccurate. For an engine, optimize a vector of signed failure distances or estimated joint yield together with area/power objectives, then validate actual candidates rather than assuming a local mathematical step is a legal layout change. PDF pp. 173–179.

At high yield, the raw probability objective becomes nearly flat. Distance objectives or temporarily inflated tolerances can expose remaining improvement. Inflating covariance is a search technique, not a claim that the foundry process has changed. Final evaluation must return to the original process model. Similarly, choosing larger devices or a different allowed device flavor may change statistical behavior; directly tuning unavailable foundry parameters is not an actionable layout decision.

Philis integration and independent checks

The annotator's placement (line 53) emits matching, thermal, centroid, symmetry and isolation-related requirements from recognized structures. This is a starting point for identifying likely mechanisms, not yet a statistical performance model. The constants near lines 37–43 include a thermal difference, proximity scale and gradient share; preserve their status as tuning defaults until calibrated to a PDK, scenario and electrical specification.

Proposed extension: give each statistical evaluation an immutable context containing global latent variables, local/spatial covariance, operating domain, model revisions and acceptance specifications. Geometry changes request a new uncertainty model when required. The optimizer can then compare robust candidates without losing which uncertainties were actually analyzed.

Meaningful checks include the exact shared-versus-local pair example, a correlated linear output with known variance, a nonlinear response with zero nominal derivative but nonzero quadratic variation, and a response with a worst temperature inside the allowed interval. Check joint yield against an independent low-dimensional integral before applying the implementation to circuit simulations. Compare statistical predictions with extracted circuit behavior on unseen variants and layouts.

Keep defect yield separate from parametric yield. Critical-area models concern shorts or opens from physical defects; process/mismatch models concern specification variation in otherwise connected circuits. Multiplying their yields requires an independence or conditional model. A final report should identify each mechanism, evidence and unresolved uncertainty rather than compressing every form of manufacturability into one unexplained percentage.
