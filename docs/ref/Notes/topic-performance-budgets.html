From circuit specifications to physical budgets

Derive shared R/C, mismatch and noise allowances from sensitivities and margins.

A layout budget is a derived allowance, not an arbitrary weight

An analog layout engine needs a reason for every requirement it imposes. “Keep this net short” is useful only after identifying what shortness protects: settling time, gain, stability, noise, offset, supply drop or another specification. Performance-driven layout translates those electrical obligations into quantities geometry can control. The translation is an approximation with a reference point, assumptions and validity range; it is not a permanent property of the net name.

Lampaert's central observation is that one fixed allocation of independent parasitic limits can reject a layout whose combined electrical behavior is acceptable. Different nets consume the same performance margin in different proportions. The more faithful constraint is often a coupled region in parasitic space, not a box of unrelated maximum lengths. The topological survey compares bound-based routing with sensitivity-weighted performance-driven routing and explains the allocation problem. Lampaert, PDF pp. 41–45; Topological Approaches, PDF pp. 182–193.

This chapter develops the translation from specification to physical action. The numerical examples are invented teaching cases, not measured Philis circuits or process constants. They illustrate what information a real budget generator must obtain.

Begin with the performance margin that actually remains

Suppose a circuit metric P must satisfy L ≤ P ≤ U. If pre-layout process analysis produces a range [Pproc,min, Pproc,max] and layout contributes the same additive shift ΔP across that range, the allowed layout shift is:

L − Pproc,min ≤ ΔP ≤ U − Pproc,max.

This follows by applying the lower bound to the smallest pre-layout value and the upper bound to the largest. It is the source's basic margin allocation. The same-shift assumption matters: a wire's effect on phase margin or settling can vary with transistor operating point, supply and temperature. For a modern engine, retain a separate bound and response model for each relevant scenario instead of relying on a single additive interval whenever that assumption fails. Lampaert, PDF pp. 34–37.

For example, phase margin must be at least 60°. Nominal simulation gives 70°, but a required process/operating scenario gives 66°. Only 6° remains in that scenario before additional modeled uncertainty is considered. Using the nominal 10° as the routing budget would spend margin already consumed by process behavior. Conversely, if the pre-layout circuit is already below 60°, placement should report that condition; no generic minimum-area policy can guarantee that parasitics will repair it.

Action and reason: create a performance ledger with specification bounds, pre-layout values by scenario, reserved model error and current extracted values. This makes budget creation auditable and prevents separate subsystems from spending the same margin twice. A reserve should be tied to measured prediction error or a stated conservative policy, not silently blended into several independent “safety factors.”

Translate parasitics with a local response model

Let p contain extracted quantities such as series resistance, grounded capacitance, coupling capacitance and mismatch descriptors. Around a reference p0, linearize each performance metric:

Pj(p) ≈ Pj(p0) + Σi Sji(pi − p0,i), where Sji = ∂Pj/∂pi.

The original zero-parasitic form is a special case with p0 = 0. Once the reference circuit already includes estimated diffusion or interconnect parasitics, add only the change from that reference; adding the full extracted value again double-counts it. Every sensitivity must identify its units: degrees per femtofarad, seconds per ohm, volts per threshold perturbation, and so forth. Lampaert, PDF pp. 42–45.

In the phase-margin example, assume the calibrated local model is ΔPM ≈ −0.02 CA − 0.05 CB, with capacitances in fF and the reference increments nonnegative. The scenario requirement becomes 0.02 CA + 0.05 CB ≤ 6. B is more sensitive per femtofarad; treating both capacitances identically wastes information.

Allocate half of the allowance to each net and the independent caps become CA ≤ 150 fF and CB ≤ 60 fF. A candidate with CA = 200 fF and CB = 20 fF violates the first cap yet consumes only 4° + 1° = 5°, so it is feasible in the coupled model. This is why allocated caps should be revisable search aids when the true contract is the sum. It is also why raw total capacitance is inadequate: a 160 fF layout split as (100, 60) consumes 5°, whereas a 200 fF layout split as (200, 0) consumes 4°.

With several metrics and scenarios, stack their sensitivity rows to obtain a system of inequalities. The feasible region is their intersection. One move can improve bandwidth while worsening offset or phase margin; retain the complete vector before selecting a weighted preference among feasible candidates.

Lower electrical allowances into geometry without losing the model

For a uniform rectangular wire in a calibrated resistive model, R = R□ L/W, where sheet resistance R□ is in ohms per square and L/W is dimensionless. A resistance limit gives Lmax = Rmax W/R□ only if width and layer are fixed and contact/via resistance has been accounted for. If vias contribute Rvia, use the remaining allowance Rmax − Rvia; a negative result means the chosen transition alone is infeasible. Lampaert §2.5.3.2, Eq. (2.33), PDF p. 51.

For a branch carrying known DC current I and permitted drop εV, Rmax ≤ εV/|I|. The current is branch current, not an arbitrary total net current: shared supply trunks carry sums of downstream currents. Current direction, simultaneous activity and bias matter. A low-resistance layer or added via may satisfy the drop while introducing capacitance or coupling elsewhere; rerun the coupled electrical check after selecting it.

A simple capacitance approximation is Cwire ≈ ca WL + cf L + Ccoupling, where ca is area capacitance density and cf represents an effective fringe term for the assumed environment. Coupling depends on neighboring routes, not only the wire itself. Derived example: for a uniform RC line with distributed capacitance to an AC reference, driven through resistance Rs and terminated by a lumped load, an illustrative Elmore first-moment expression is τ ≈ Rs(Cwire + CL) + Rwire(CL + Cwire/2). This expression follows by integrating each infinitesimal wire resistance against its downstream capacitance; the average wire-capacitance contribution is Cwire/2. It is our teaching derivation, not an equation quoted from the cited pages. Apply it to coupling only under a stated effective-load approximation. Increasing width reduces Rwire but increases the area-dependent capacitance seen through driver resistance Rs. This derivation explains why blindly maximizing wire width is not an electrical optimum. The model omits inductance, nonlinear driver behavior and detailed distributed coupling, so it is a screening model with a stated domain. Lampaert, PDF pp. 47–50.

Engine mapping: ParasiticBudget stores a drawn-length cap. Its generic extract helper contains a documented 1 mm fallback, but that helper is not the active per-net budget path: the annotator already converts class/load-derived capacitance allowances to length using the process wire capacitance per micrometer. Extend this path with a derivation record containing the parent electrical requirement, allowed R/C contribution, assumed layer, width, via allowance and reference geometry. Retain the fast length check when appropriate, but invalidate or recompute it when those assumptions change. One millimeter on different layers or widths does not imply equal R/C, and a class/load heuristic does not by itself prove a circuit specification.

Independent caps approximate a coupled feasible region

One implementation can keep the coupled row as the actual requirement and derive net prices from its active multiplier. A marginal cost on pi is then proportional to the row sensitivity Sji and the scarcity of that requirement's remaining headroom. Multiple active rows contribute multiple prices. These prices indicate where a small improvement is valuable; they are not substitutes for evaluating the original coupled inequalities. A multiplier is interpretable only for the particular objective, scales and local optimum from which it was obtained.

Another implementation can allocate conservative independent caps for a simpler router, then reallocate after routing exposes which nets are expensive. Store the allocation as a child of the shared parent requirement so that unused allowance can move without changing the specification. Freeze prices within one search epoch, because changing the energy during every move makes annealing comparisons inconsistent. The source surveys precisely the tension between simple per-net constraints and direct performance cost. Topological Approaches, PDF pp. 184–193.

Statistical variation and model error also consume margin

If uncertain parasitic increments have covariance Σp and the performance sensitivity is the column vector s, then σP² ≈ sᵀΣp s. This follows from linear covariance propagation. For sensitivity magnitudes 0.02 and 0.05 degrees/fF, both standard deviations 10 fF and correlation 0.8, the variance is 0.2² + 0.5² + 2(0.2)(0.5)(0.8) = 0.45 degree², giving σP ≈ 0.671°. Ignoring correlation gives √0.29 ≈ 0.539°, an optimistic margin here. If the sensitivities have opposite signs, the same correlation can instead reduce output variation. Preserve the signs and covariance. Design Centering, PDF p. 111, p. 183.

A conservative single-output lower-bound screen can require Ppred − kσP − emodel ≥ L, where emodel is a defined bound or reserve for prediction error. It becomes a probabilistic statement only under the distribution and linearization assumptions used to interpret k. It is not automatically a joint yield claim over multiple outputs and operating conditions. Uncertain systematic model bias should not be merged into independent random mismatch merely to obtain a smaller root-sum-square number.

Likewise, thermal gradient and random mismatch are different mechanisms. A deterministic temperature difference can shift the mean; process variation changes the distribution; nonlinear interactions may alter both. Record which terms are estimated as worst-case bounds, covariance contributions or unresolved modeling error. See robust design and yield for the complete acceptance event.

Refresh sensitivity models when the layout leaves their domain

Compute sensitivities with an appropriate circuit method: perturbation, direct sensitivity or adjoint analysis. An adjoint can make many parameter derivatives efficient for one scalar response; it does not generally produce arbitrarily many independent response gradients for free. Choose perturbation sizes large enough to exceed solver noise but small enough to remain local, and compare forward and reverse estimates for critical quantities. Lampaert, PDF pp. 43–45; Design Centering, PDF pp. 72–75.

Normalize a trust region using physical scales D: ||D⁻¹(p − p0)|| ≤ Δ. This prevents a numerical unit change from changing the permitted physical step. After evaluating a candidate, compare actual and predicted changes in every critical metric. If a sensitivity predicts a 1° phase-margin loss and simulation finds 3°, shrink the domain, increase the error reserve, and refresh the model near the relevant candidate. A rejected prediction is valuable evidence, not noise to average away.

Trigger refresh after a topology change, device resize, variant or finger change, operating-region change, altered aggressor neighborhood, or active worst-case scenario change. These can cause discontinuities that a small coordinate perturbation model cannot represent. Keep a cache key containing netlist, device models, PDK, extraction setup, scenario and geometry revision. This is why the performance loop needs explicit model identity rather than a global array of unnamed weights.

A concrete implementation contract and checks

for each specification and required scenario:
    establish baseline performance and available headroom
    define parasitic variables, units and ownership
    estimate sensitivities and verify perturbation consistency
    build coupled performance inequalities plus uncertainty reserve
    derive cheap geometric child constraints with explicit assumptions
search with those children while retaining the electrical parent
extract selected complete routes; compare prediction with simulation
reallocate, refresh or report insufficient headroom as justified

The existing Requirements tier split can hold these rules, but shared electrical constraints need identities and scopes that survive lowering. The current per-net length rule deliberately treats an unrouted net's zero length as passing; therefore connectivity must be checked separately before interpreting the parasitic result. A short or missing route cannot count as an electrically successful low-capacitance solution.

Validate dimensions with a known sheet-resistance example; compare predicted with extracted R while changing width, layer and via count independently. Validate coupled allocation with the worked two-net example and a second metric that makes the first tradeoff infeasible. Check correlated propagation against sampled linear models. Finally compare candidate rankings against actual circuit responses across held-out geometries and scenarios. These checks establish whether the budget protects the intended performance, which is the reason to generate it.
